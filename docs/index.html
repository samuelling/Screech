    HOW TO SCREECH

    1. AGREE ON A PASSPHRASE

    Pick one together, in person. Both type it into KEY>. It never travels over the sound; only the scrambled note does.

    2. LISTEN

    The receiver opens LISTEN and presses LISTEN, then allows the microphone. Nothing is recorded or saved.

    3. SEND

    The sender types a note (up to 280 characters), holds the device a few inches from the receiver, volume up, and presses SEND. The receiver's lights go CD (carrier) then RD (receiving), and the note appears.

    SPEEDS

    STURDY: slow chiming tones, the most reliable. QUICK: half the time, wants a quieter room. CLASSIC: the real 300-baud modem screech. The receiver hears all three automatically.

    IS IT REALLY SECRET?

    Yes, with a passphrase. The note is encrypted with AES-256 before it becomes sound, using a key made from your passphrase (PBKDF2, 200,000 rounds). Anyone can record the screech, but without the passphrase it's noise, and a tampered note won't open. Without a passphrase it's an OPEN NOTE that anyone with a decoder can read. Pick a passphrase that's hard to guess; a few unrelated words work well.

    NOTES AS SOUND FILES

    SAVE AS SOUND makes an audio file of the note that you can text or email. The other person opens it with DECODE A SOUND FILE (or in Screech on iPhone). Notes survive most voice-memo compression.

    IF A NOTE DOESN'T ARRIVE

    Move closer, turn the volume up, cut background noise, or switch to STURDY, then send again. The receiver keeps listening. Across a room, echoes can garble a note. Browsers sometimes clean up microphone sound for calls; Screech asks them not to, but if notes keep failing, try another browser.

    WORKS WITH

    Screech for iPhone, this page on any phone or computer, and the Modem in RetroSynths. They all understand each other.
